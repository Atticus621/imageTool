# ROI 绘画系统 — 完全解耦 + 测试保障

## 问题根因
canvas.py 有 11 处 isinstance + 直接访问私有字段（`_corners/_radius/_center`），每次改形状内部都出 bug。

## 目标
1. 形状类完全自包含，canvas 不访问任何私有字段
2. canvas 零 isinstance，全靠多态
3. 每次修改必须通过测试

---

## 修改清单

### A. 形状类补全

**circle.py** — 补全缺失内容：
- 添加类属性 `shape_type/tool_label/draw_mode/has_edges`
- 添加 `update_from_drag(start, current)` 方法
- 末尾 `ShapeRegistry.register(CircleShape)`

**polygon.py** — 补全：
- 添加类属性
- 末尾 `ShapeRegistry.register(PolygonShape)`

### B. canvas.py — 消除所有 isinstance + 私有字段访问

当前问题代码：
```python
# isinstance 检查（11处）
isinstance(self._drawing_shape, PolygonShape)
isinstance(self._drawing_shape, RectangleShape)
isinstance(self._selected_shape, RectangleShape)

# 直接访问私有字段
self._drawing_shape._corners = [...]  # canvas 不应该碰这个
self._drawing_shape._radius = r       # canvas 不应该碰这个
self._selected_shape._center          # canvas 不应该碰这个
```

修复方案：
1. `_start_drawing`: 用 `ShapeRegistry.get(tool)` 创建，不再 if/elif
2. `_update_drawing`: 用 `shape.update_from_drag(start, pos)` 多态
3. `_finish_drawing`: 用 `shape.bounding_rect()` 最小尺寸检查
4. `_do_resize_edge`: 用 `shape.resize_edge_by_delta(edge, dx, dy)` 多态
5. `_validate_shape`: 用 `state.get("type")` 判断，不再 isinstance

### C. hit_test.py — 消除 isinstance

```python
# 当前：isinstance 检查具体类型
has_rotation = isinstance(shape, (RectangleShape, PolygonShape))

# 修复：用 shape._has_rotation 属性
if shape._has_rotation and shape.selected: ...

# 当前：isinstance 检查边
if isinstance(shape, RectangleShape): edge = shape.find_hit_edge(pos)

# 修复：所有形状都调用 find_hit_edge，多态处理
edge = shape.find_hit_edge(pos)
if edge: candidates.append(...)
```

### D. 统一 DRAWING 状态

当前有 `DRAWING_RECT/DRAWING_CIRCLE/DRAWING_POLYGON` 三个状态。
改为统一 `DRAWING_SHAPE`，通过 `shape.draw_mode` 区分行为。

### E. 测试文件

`test/roi/test_shapes.py` — 覆盖所有核心功能：
- 创建/移动/缩放/旋转每种图形
- 中心点始终在内部
- 旋转 360° 无跳变
- 包含点测试
- 边命中测试
- ShapeRegistry 注册正确
