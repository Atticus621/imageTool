# 计划：类文档深度重写

## 问题
27个类的文档质量不足，核心差距：
1. 缺少方法参数表（方法只有一句话说明）
2. 缺少属性/配置说明
3. 缺少使用流程说明
4. 缺少与替代方案的对比
5. 代码示例太简短

## 类文档模板（基于ml.html SVM标准）

每个类应包含：
```
1. 概念说明（是什么、怎么工作、什么时候用）
2. 创建方式（工厂方法/构造函数 + 参数表）
3. 方法列表（每个方法带参数表和返回值）
4. 属性/配置（getter/setter或配置参数）
5. 相关常量（如有）
6. 使用流程（典型生命周期）
7. 与替代方案的对比
8. 完整代码示例
```
