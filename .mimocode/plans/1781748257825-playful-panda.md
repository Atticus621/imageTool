# 计划：修复矩形绘制、调整大小、旋转、中心点显示

## 目标

只跑通矩形的四个功能：
1. 手动绘制矩形
2. 手动调整大小
3. 旋转手柄旋转（显示在图形外侧，按照中心点进行旋转，以水平向右为x轴）
4. 中心点显示

## 问题分析

### 问题1：旋转不是围绕中心点
- **原因**：`boundingRect().center()` 返回包含 pen 宽度的矩形中心，不是实际绘制矩形的中心
- **解决**：使用 `rect().center()` 并设置 `transformOriginPoint`

### 问题2：旋转手柄位置不正确
- **原因**：手柄位置计算使用了错误的中心点
- **解决**：使用 `rect().center()` 计算手柄位置

### 问题3：中心点显示位置不正确
- **原因**：CenterLabelItem 的位置没有正确设置
- **解决**：使用 `rect().center()` 设置中心标签位置

## 修改方案

### 修改文件：`test/drawing_tool.py`

#### 1. 修改 RotationHandleItem._update_position()
```python
def _update_position(self):
    parent = self._parent_item
    center = parent.rect().center()  # 使用 rect() 而不是 boundingRect()
    self.setPos(center.x(), center.y() - ROTATION_HANDLE_OFFSET)
```

#### 3. 修改 BaseShapeItem._setup_handles()
```python
def _setup_handles(self):
    ...
    self._rotation_handle = RotationHandleItem(self)
    self._center_label = CenterLabelItem(self)
    self._show_handles(False)
    # 设置旋转中心点为 rect().center()
    if hasattr(self, 'rect'):
        self.setTransformOriginPoint(self.rect().center())
```

#### 4. 修改 BaseShapeItem._show_handles()
```python
def _show_handles(self, show):
    if self._rotation_handle:
        self._rotation_handle.setVisible(show)
        if show:
            self._rotation_handle._update_position()
    if self._center_label:
        self._center_label.setVisible(show)
        if show:
            center = self.rect().center()  # 使用 rect()
            self._center_label.setPos(center.x(), center.y())
```

## 测试计划

### 测试1：旋转中心验证
```python
def test_rotation_center():
    item = RectItem(QRectF(100, 100, 200, 100))
    rect_center = item.rect().center()  # (200, 150)
    
    # 设置旋转中心
    item.setTransformOriginPoint(rect_center)
    
    # 旋转90度
    item.setRotation(90)
    
    # 验证中心点位置不变
    scene_center = item.mapToScene(rect_center)
    assert abs(scene_center.x() - 200) < 1
    assert abs(scene_center.y() - 150) < 1
```
