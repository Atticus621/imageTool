# 尺子工具实现方案

## 目标
在图像查看器上添加交互式尺子工具，支持拖拽画线并显示像素距离，预留标定和节点集成扩展接口。

## 架构设计

### 分层结构

```
systems/ruler/              # 测量逻辑层（独立于UI）
  ├── __init__.py
  ├── measure.py            # 测量计算、标定接口预留
  └── calibration.py        # 标定系统接口（预留）

ui/widgets/ruler_overlay.py # 视觉交互层（叠加在图像查看器上）

ui/main_window.py           # 集成入口（添加工具栏按钮、菜单）
ui/image_viewer.py          # 修改（添加overlay支持）
```

### 为什么选择这个结构

1. **`systems/ruler/`** - 测量逻辑独立于UI，未来节点系统可以直接调用 `RulerMeasure` 类
2. **`ui/widgets/ruler_overlay.py`** - 视觉交互层，叠加在图像查看器上，不污染现有组件
3. **解耦设计** - ruler系统通过信号/接口与UI通信，未来集成节点系统时无需修改核心逻辑

## 实现步骤

### Step 1: 创建测量逻辑层 `systems/ruler/measure.py`

```python
from dataclasses import dataclass
from typing import Optional
import numpy as np

@dataclass
class MeasurementResult:
    """测量结果数据类"""
    start_point: tuple[int, int]  # 起点像素坐标 (x, y)
    end_point: tuple[int, int]    # 终点像素坐标 (x, y)
    pixel_distance: float         # 像素距离
    real_distance: Optional[float] = None  # 实际距离（标定后）
    unit: str = "px"              # 单位

class RulerMeasure:
    """尺子测量工具 - 核心逻辑"""
    
    def calculate_pixel_distance(self, p1: tuple, p2: tuple) -> float:
        """计算两点间像素距离"""
        return np.sqrt((p2[0] - p1[0])**2 + (p2[1] - p1[1])**2)
    
    def create_measurement(self, start: tuple, end: tuple) -> MeasurementResult:
        """创建测量结果"""
        pixel_dist = self.calculate_pixel_distance(start, end)
        return MeasurementResult(
            start_point=start,
            end_point=end,
            pixel_distance=pixel_dist,
        )
    
    # 预留标定接口
    def set_calibration(self, pixel_per_unit: float, unit: str = "mm"):
        """设置标定比例（预留）"""
        pass
    
    def get_real_distance(self, pixel_distance: float) -> Optional[float]:
        """获取实际距离（预留）"""
        return None
```

### Step 2: 创建视觉交互层 `ui/widgets/ruler_overlay.py`

功能：
- 继承 `QWidget`，作为透明叠加层覆盖在图像查看器上
- 处理鼠标事件：按下→拖拽→释放，绘制测量线
- 实时显示像素距离（跟随鼠标移动）
- 支持多条测量线（列表管理）
- 清除功能

关键实现点：
- 使用 `setAttribute(Qt.WA_TransparentForMouseEvents, False)` 接收鼠标事件
- 在 `paintEvent` 中绘制所有测量线和距离标签
- 信号：`measurement_added(MeasurementResult)`, `measurement_cleared()`

### Step 3: 修改 `ui/image_viewer.py`

添加 overlay 支持：
- 在 `ImageViewerWidget` 中添加 `RulerOverlay` 实例
- 提供 `toggle_ruler()` 方法开关尺子工具
- overlay 根据当前显示图像的尺寸自动调整位置

### Step 4: 修改 `ui/main_window.py`

添加工具栏和菜单：
- 工具栏添加 "📏 尺子" 按钮（toggle）
- 视图菜单添加 "显示尺子工具" 选项
- 状态栏显示当前测量结果

## 扩展预留

### 标定系统预留
- `RulerMeasure.set_calibration()` 接口已预留
- `MeasurementResult` 包含 `real_distance` 和 `unit` 字段
- 未来实现标定系统时，只需在 `systems/ruler/calibration.py` 中实现具体逻辑

### 节点集成预留
- `RulerMeasure` 是纯逻辑类，不依赖 Qt，可被节点直接调用
- `MeasurementResult` 是标准数据类，可作为节点输出数据
- 未来可创建 `RulerNode` 节点，内部调用 `RulerMeasure`

## 验证方法

1. 启动应用 `python main.py`
2. 加载图像到图像查看器
3. 点击工具栏 "尺子" 按钮开启尺子工具
4. 在图像上拖拽画线，验证：
   - 线条正确绘制
   - 距离标签实时显示
   - 释放后距离固定显示
5. 再次点击按钮关闭尺子工具，验证线条消失
6. 检查状态栏显示测量信息
